## N02：如何同时保持共享规范引用与规则只读

- **发现位置/问题**：09 §4 要求 tuple 成员仍是规范对象，并指出 tuple 不能保护成员字段。

- **验证**：未来对象可达性遍历、同刻未激活隔离、违规改 available_time、选择顺序/快照测试。
- **同步**：09 受限视图实现方式、02 selection 职责。
