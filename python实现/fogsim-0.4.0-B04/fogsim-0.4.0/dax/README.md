# DAX 输入来源

本目录 22 份 XML 从本次对话附件 `Fog-Computing-multiDeviceDebug.zip` 的顶层 `Fog-Computing-multiDeviceDebug/dax/` 逐字节复制，未修改。具体 SHA256 见 `SOURCES.json`。标准 20 类型的映射由原 Java `DAGType` 和 `DAGTypePath.getDAGTypePathForSubmit` 核对。

HEFT_paper.xml 和 floodplain.xml 可由纯解析器读取，不分配新的标准类型编号。jobCount/childCount 声明不决定拓扑；HEFT_paper 的声明不符只产生诊断。解析及采样验收见 `../docs/STEP2-PROGRESS.md`。
